What is NagaraAI?

NagaraAI is a full-stack civic issue management platform designed for Bengaluru (and adaptable to any city). It lets citizens report problems like potholes and garbage, while ward officers, field officers, and commissioners track, dispatch, and analyse resolution in real time.

Who is this guide for?

Absolute beginners. You do not need to know Python, React, or databases. You only need to be comfortable typing commands and following steps in order. Every step is explained in plain language.

Prerequisites — What to Install First

You only need two things installed on your computer: Git and Docker Desktop. Everything else (Python, Node, PostgreSQL) runs inside Docker containers — you do not install them on your machine.

1 · Install Git

Git lets you download the project code.

  • Windows: Download from git-scm.com/download/win → run installer → accept all defaults
  • Mac: Open Terminal → type git --version → macOS will prompt you to install it automatically
  • Linux (Ubuntu/Debian): sudo apt-get install git

✅ Verify: open a terminal and run git --version — you should see a version number like git version 2.44.0

2 · Install Docker Desktop

Docker runs the entire app in isolated containers. It is the recommended and easiest way.

  • Windows: Download from docker.com/products/docker-desktop → run installer → restart when prompted
  • Mac: Same link above, choose "Mac with Apple Silicon" or "Mac with Intel Chip"
  • Linux: Follow docs.docker.com/engine/install for your distro
⚠️ Windows users: Docker Desktop requires WSL 2 (Windows Subsystem for Linux). The installer will guide you through enabling it. If asked, restart your computer and re-run the Docker installer.

✅ Verify: open a terminal and run docker --version — you should see Docker version 26.x.x or similar

💡 Tip: After installing Docker Desktop, make sure it is running (look for the Docker whale icon in your system tray/menu bar) before proceeding. Commands will fail if Docker is installed but not started.

1 Get the Code

Open a terminal (PowerShell on Windows, Terminal on Mac/Linux) and run:

git clone https://github.com/your-org/nagaraai.git
cd nagaraai
📁 What you now have: A folder called nagaraai containing backend/, frontend/, and docker-compose.yml. All future commands must be run from inside this folder.

If you already have the folder (downloaded as a ZIP), just cd into it:

cd path/to/nagaraai

2 Configure Environment Variables

The backend needs a small configuration file called .env. Create it by copying the example:

Windows (PowerShell)

copy backend\.env.example backend\.env

Mac / Linux

cp backend/.env.example backend/.env

Now open backend/.env in any text editor (Notepad, VS Code, etc.) and check these values:

VariableDefault ValueWhat to do
DATABASE_URLpostgresql://nagaraai:nagaraai123@db:5432/nagaraai_dbLeave as-is (Docker handles this)
SECRET_KEYyour-super-secret-key…Change to any long random string for security
ALGORITHMHS256Leave as-is
ACCESS_TOKEN_EXPIRE_MINUTES1440Leave as-is (24-hour sessions)
WATSONX_API_KEYemptyLeave blank for now — the app works without it
WATSONX_PROJECT_IDemptyLeave blank for now
💡 Minimum viable setup: For a quick local test, you only need to change SECRET_KEY. Everything else works with the defaults.

3 Start All Services with Docker

Make sure Docker Desktop is running, then in your terminal (inside the nagaraai folder), run:

docker compose up --build
What this does: Docker reads docker-compose.yml and:
  • Downloads the PostgreSQL 16 image (~80 MB, one-time)
  • Builds the Python/FastAPI backend image
  • Builds the React frontend image
  • Starts all three containers and connects them on a private network
⏳ First run takes 3–8 minutes because Docker downloads and builds everything. Subsequent starts take under 30 seconds.

You know it worked when you see output like:

nagaraai_backend  | INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
nagaraai_frontend | Compiled successfully!
nagaraai_frontend | 
nagaraai_frontend | You can now view nagaraai-frontend in the browser.
nagaraai_frontend |   Local:  http://localhost:3000

Keep this terminal window open while you use the app. To run in the background instead, add -d:

docker compose up --build -d

4 Seed the Database

The database starts empty. Run this one-time command to populate it with Bengaluru wards, contractors, and four demo user accounts:

docker compose exec backend python seed.py

You should see:

✅ Database seeded successfully.

Demo logins:

  Field Officer:  field@demo.com / demo1234
  Ward Officer:   ward@demo.com / demo1234

💡 This command is safe to run multiple times — it checks for existing records and only inserts missing ones, so running it again will not create duplicates.

6 Enable IBM watsonx.ai (Optional)

By default, NagaraAI uses a built-in rule-based classifier that works with zero external credentials. To unlock full AI classification (Granite-13B LLM for Kannada/English NLP, priority scoring, and SLA suggestions), connect IBM watsonx.ai:

Step A — Get IBM Cloud credentials

  1. Create a free account at cloud.ibm.com/registration
  2. Go to IBM watsonx → create a project
  3. Navigate to Manage → General → Project ID — copy this value
  4. Go to IBM Cloud → Manage → Access (IAM) → API Keys → create a new API key — copy it

Step B — Add credentials to backend/.env

WATSONX_API_KEY=your-actual-api-key-here
WATSONX_PROJECT_ID=your-actual-project-id-here
WATSONX_URL=https://us-south.ml.cloud.ibm.com

Alternative: Run Without Docker

If you cannot use Docker, you can run each service manually. This requires Python 3.12+, Node 20+, and a local PostgreSQL 16+ installation.

Backend (FastAPI)

cd nagaraai/backend

# Create virtual environment
python -m venv venv

# Activate it
venv\Scripts\activate          # Windows PowerShell
source venv/bin/activate       # Mac / Linux

# Install dependencies
pip install -r requirements.txt

# Configure environment
copy .env.example .env         # Windows
cp .env.example .env           # Mac/Linux
# Edit .env — set DATABASE_URL to your local PostgreSQL connection string

# Create tables + demo data
python seed.py

# Start the API server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Frontend (React)

cd nagaraai/frontend

# Install dependencies
npm install

# Start the development server
npm start
⚠️ DATABASE_URL for manual setup: Change the host from db (Docker service name) to localhost: 
DATABASE_URL=postgresql://nagaraai:nagaraai123@localhost:5432/nagaraai_db

Troubleshooting

❌ "Cannot connect to the Docker daemon" or "docker: command not found"

Docker Desktop is not running. Open Docker Desktop from your Start Menu / Applications folder and wait for it to fully start (the whale icon in the taskbar/menu bar turns steady, not animating).

❌ Port 3000 or 8000 already in use

Another program is using that port. Find and stop it, or change the port in docker-compose.yml:

ports:
  - "3001:3000"   # Change left number to any free port

Then access the app at http://localhost:3001 instead.

❌ Frontend shows "Network Error" or blank data

The backend might still be starting. Wait 10–15 seconds and refresh. If it persists:

docker compose logs backend

Look for red error lines. Common causes: wrong DATABASE_URL in .env, or the database container hasn't finished initialising.

❌ Seed command fails: "relation does not exist"

The backend hasn't run yet (tables are created on first startup). Make sure the backend is running and healthy first:

docker compose ps                        # all services should show "running"
curl http://localhost:8000/health        # should return {"status":"ok"}

❌ Changes to .env not taking effect

Environment variable changes require a container restart:

docker compose down
docker compose up --build

🔍 View logs for a specific service

docker compose logs backend      # backend logs
docker compose logs frontend     # frontend logs
docker compose logs db           # database logs
docker compose logs -f backend   # follow/live-stream logs

🔍 Check which containers are running

docker compose ps

All three services (nagaraai_db, nagaraai_backend, nagaraai_frontend) should show status Up.

Stopping & Resetting

Stop the app (keep data)

docker compose down

Containers stop but the database volume (pgdata) is preserved. Next docker compose up resumes where you left off.

Full reset (delete everything including data)

docker compose down -v

The -v flag deletes the database volume. After this, you must run python seed.py again to repopulate demo data.

Rebuild after code changes

docker compose up --build

Forces Docker to rebuild images. Required after changing requirements.txt, package.json, or Dockerfiles.

Pre-flight checklist before starting

  • Docker Desktop is installed and running
  • You are inside the nagaraai/ folder in your terminal
  • backend/.env file exists (copied from .env.example)
  • Ports 3000, 8000, and 5432 are not used by other apps
  • You have ~500 MB free disk space for Docker images
